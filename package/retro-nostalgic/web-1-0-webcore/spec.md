# Web 1.0 / Webcore

## Signature
browser-default type, blue underlined links, tiled backgrounds, beveled
buttons, animated GIFs
visitor counters
`--depth: 1`

## Suited for
personal sites, art projects, developer communities, games, nostalgic web
experiences

## Layout
visible document flow, table-like framing, persistent side navigation
stacked page sections that feel hand-assembled rather than app-shell polished

## Colors
classic browser-safe palette: white or tiled grounds, blue underlined links,
purple visited states
direct high-contrast utility colors
- primary: classic browser blue
- secondary: visited-link purple
- base-100/200/300: white, light gray, silver
- depth: `--depth: 1`

## Imagery
animated GIFs, web badges, pixel dividers, counters, tiny icons, tiled
textures, fan graphics
plainly embedded photographs

## Density
high link and artifact density with descriptive headings, lists, and visible
grouping
avoid illegible novelty backgrounds behind text
use the `*-sm` component size variants for compact working density

## Motion
small looping GIFs, marquees, blinking status marks, simple hover swaps as
nostalgic artifacts
not the only way to convey information

## Shape
beveled buttons, one-pixel table borders, horizontal rules, framed boxes,
banner strips
native form controls
`--radius-*` 0 or 0.25rem

## Typography
browser-default serif, system sans, or monospace families; obvious link
styling preserved
decorative web fonts limited to banners or logos
Suggested: Tinos, Arimo, Cousine, Comic Neue, VT323

## Origins
1991–late 1990s as a source period; later nostalgia label; early World Wide
Web communities
first public pages appeared after Tim Berners-Lee released the WWW software
more broadly in 1991
— shaped by limited HTML, slow networks, small displays,
and hand-authored documents rather than a coordinated aesthetic; "Webcore"
later turned tables
default links, badges, counters, tiled backgrounds, and GIFs into nostalgic
style markers
