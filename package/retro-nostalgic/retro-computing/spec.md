# Retro Computing

## Signature
CRT glow, bitmap fonts, window chrome, limited palettes, scanlines,
floppy-disk icons
`--noise: 1`, `--depth: 1`

## Suited for
developer tools, games, music software, portfolios, emulators, technology
museums

## Layout
vintage operating-system desktop with overlapping windows, menu bars, icon
grids, dialogs,
and persistent status regions

## Colors
one historically coherent system palette — beige and navy, grayscale
Macintosh, or phosphor black
— keeping color depth deliberately limited
- primary: navy (beige-and-navy palette)
- secondary: muted teal
- base-100/200/300: monitor beige, putty, darker case beige
- texture: `--noise: 1`
- depth: `--depth: 1`

## Imagery
CRT screens, floppy disks, bitmap icons, old peripherals, window captures,
pixel cursors
authentic software or hardware details

## Density
medium-to-high desktop density with compact menus, lists, and dialogs
preserving clear focus and z-order among overlapping windows
use the `*-sm` component size variants for compact working density

## Motion
window open and close steps, hourglass or watch cursors, disk activity, CRT boot
discrete progress changes instead of fluid app motion

## Shape
pixel window chrome, square icon wells, one-pixel rules, inset panels, title
bars
hard-edged buttons from the selected system era; `--radius-*` 0 or 0.25rem

## Typography
period-appropriate bitmap, system, or monospace type at native integer sizes
keeping every control label crisp and historically consistent
Suggested: VT323, Press Start 2P, IBM Plex Mono, Silkscreen, Pixelify Sans

## Origins
source hardware from the 1970s–1990s; preservation and revival ongoing;
home-computer
workstation, arcade
and software cultures worldwide; both a preservation practice and a visual
category
— enthusiasts maintain and emulate older computers, operating systems, games,
displays
and peripherals while designers selectively reuse bitmap fonts, window
chrome, beige hardware
scanlines
and constrained palettes; spans many incompatible platforms and decades
so it has no single visual origin
Sources: computerhistory.org/timeline
