# Data-Dense Utilitarian UI

## Signature
compact spacing, dense tables, aligned numerals, visible gridlines,
restrained palette
utilitarian controls

## Suited for
developer tools, operations software, analytics, trading, logistics, internal
enterprise systems

## Layout
resizable panes, sticky headers, aligned columns, persistent filters
predictable tool regions that keep high-value data visible during comparison

## Colors
- primary: subdued analytical blue
- secondary: slate or muted teal
- base-100/base-200/base-300: closely spaced cool white, blue-gray, and gray
  surfaces

## Imagery
sparklines, dense charts, topology diagrams, maps, tiny status glyphs
no decorative photography in working views

## Density
intentionally high with four- and eight-pixel spacing, compact row heights
user-controlled expansion for verbose records; use `*-sm` size variants

## Motion
sorting, filtering, and panel changes nearly immediate; preserve scroll position
no motion that delays repeated expert actions

## Shape
compact rectangles, two- to four-pixel radii, visible gridlines, precise
splitters
minimal surface elevation
`--radius-*` set to 0 or 0.25rem

## Typography
condensed sans-serif for labels, mono or tabular-numeral face for values,
aligned decimals
clear row rhythm
Suggested: IBM Plex Sans, IBM Plex Mono, Roboto Condensed, Source Sans 3,
JetBrains Mono

## Origins
1970s–present; scientific, financial, industrial, and enterprise software
a practical lineage rather than a named aesthetic movement — industrial
control rooms
financial terminals
scientific displays, spreadsheets
contemporary design reframes the density with clearer typography, alignment
and interaction states
