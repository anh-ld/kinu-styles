# Metro / Modern UI

## Signature
typography-led hierarchy, flat tiles, edge-to-edge imagery, strict alignment,
minimal chrome
lateral motion

## Suited for
media hubs, dashboards, kiosks, Windows-inspired products, information-first
interfaces

## Layout
compose asymmetric tile fields on a strict baseline grid, let key content
reach the viewport edge
use panoramic horizontal groupings instead of card stacks

## Colors
- primary: cobalt or cyan
- secondary: a second bold system hue, e.g., magenta or green
- base-100: crisp white
- base-200: light gray
- base-300: charcoal (light scheme); tightly stepped charcoals in dark

## Imagery
photography cropped edge to edge inside tiles, direct subject framing
captions or large type beside images rather than on decorative frames

## Density
many destinations at once, each tile internally spare; scale
and alignment make the information map immediately scannable

## Motion
lateral pivots, panoramic scrolling
staggered tile entrances that reinforce the horizontal information architecture

## Shape
square or rectangular tiles with sharp corners, flush edges, minimal borders
proportion replaces ornament
`--radius-*` set to 0 or 0.25rem

## Typography
light open sans-serif at dramatic sizes for navigation and headlines,
flush-left text
type treated as the primary interface graphic
Suggested: Source Sans 3, Open Sans, Archivo, Roboto Condensed, Barlow

## Origins
mid-2000s roots, formalized around 2010; Microsoft, Redmond
evolved from earlier work in Windows Media Center and Zune, defined Windows
Phone 7 (2010)
drew on transport signage — strong typography, motion, flat planes, content
before decorative chrome
