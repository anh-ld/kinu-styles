# Fluent Design

## Signature
acrylic translucency, soft elevation, light highlights, layered panels,
adaptive components
subtle motion

## Suited for
Microsoft-platform apps, enterprise software, productivity suites,
cross-device products

## Layout
arrange navigation, command bars, content panes,
and dialogs as a legible depth stack that adapts from spacious desktop windows
to compact device frames

## Colors
- primary: system blue
- secondary: muted teal or violet
- base-100/base-200/base-300: closely stepped cool white and gray surfaces
- depth: `--depth: 1`

## Imagery
crisp productivity icons, restrained editorial photography
diagrams that sit cleanly inside adaptive content panes

## Density
medium to high working density with clear pane boundaries, compact commands
breathing room around the current task; use `*-sm` size variants

## Motion
subtle depth, parallax, reveal highlights
coordinated object movement that preserves spatial continuity

## Shape
moderate radii, thin outlines, soft elevation, lightly luminous edges
controls precise rather than pillowy
`--radius-*` between 0.25rem and 1rem

## Typography
Segoe-like humanist sans-serif, compact but readable labels
weight changes used sparingly across dense command surfaces
Suggested: Noto Sans, Inter, Source Sans 3, Manrope

## Origins
2017–present; Microsoft, Redmond
announced at Build 2017 as the next cross-device design language for Windows
organized around light, depth, motion, material, and scale
— built on Metro's clarity while restoring layered and atmospheric effects
for touch, pen
mixed reality, and traditional screens
