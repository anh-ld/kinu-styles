# Aqua UI

## Signature
gel buttons, candy colors, glossy highlights, pinstripe surfaces, translucent
chrome
dimensional icons

## Suited for
retro desktop experiences, music players, nostalgic utilities,
early-2000s-inspired products

## Layout
content framed as polished desktop windows with visible title bars, toolbars,
side wells
and bottom status regions arranged for direct manipulation

## Colors
- candy blue, graphite, and pearl surfaces with strong vertical gradients,
  white specular bands
  and saturated traffic-light accents
- token mapping: `primary` = candy blue, `secondary` = aqua or graphite,
  `base-100` = pearl white
  `base-200` = pale silver, `base-300` = cool gray
- `--depth: 1`

## Imagery
glossy dimensional icons, watery textures, polished hardware
bright desktop-style illustrations rendered from a consistent three-quarter
angle

## Density
medium desktop density; compact toolbars and lists balanced by broad glossy
controls
and clear window regions

## Motion
gel-button compression, liquid progress sheen, drawer slides
elastic window transitions inspired by early desktop interfaces

## Shape
capsules, glassy wells, beveled window chrome, circular status lights
convex controls with conspicuous highlights
`--radius-*` between 0.75rem and 1.5rem

## Typography
friendly screen-optimized sans-serif for compact labels, darker title-bar text
crisp anti-aliased numerals against glossy surfaces
Suggested: Varela Round, Ubuntu, Nunito Sans, Exo 2, Quicksand

## Origins
introduced 2000; Apple, California; unveiled with Mac OS X on January 5,
2000; translucent menus
luminous color
soft shadows, pinstriped surfaces, and gel-like controls designed
to make a new Unix-based OS feel approachable
became a defining reference for glossy early-2000s software
Sources: apple.com/newsroom/2000/01/05Apple-Unveils-Mac-OS-X
